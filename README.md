# Math Detective G2 - 100 Missions & Diagnostic Assessment

An interactive, gamified assessment web app for Grade 2 mathematics, integrating:
- **Singapore Math (CPA Approach & Bar Models)**
- **PISA Real-World Problem Solving Contexts**
- **100 Comprehensive Curriculum Questions (Units 1 to 7)**
- **Dual English & Thai Audio Voice-Over**
- **Diagnostic Scoring Matrix & Google Sheets Synchronization**
